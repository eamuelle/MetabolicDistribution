# MetabolicDistribution

Last updated: 29 April 2026
Authors: Emmi Mueller, Jay T. Lennon

This repository contains the analysis pipeline of the manuscript "Metabolic inequality in microbial communities". Here, we quantify single-cell metabolism in microbial communities and show that metabolic activity followed a long-tailed distribution best described by a lognormal model across aquatic, terrestrial, and host-associated ecosystems. We also assess the consequences of metabolic inequality through a stochastic simulation model linking single-cell metabolic activity to community respiration via enzyme kinetics.
